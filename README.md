# JENNIE RUBY

A personal Android icon pack for Nova Launcher, designed for the TECNO POVA 4.

## Visual direction
- Deep black, ruby red and crimson, with dusty rose accents.
- Velvet, dark roses, ribbons, pearls and elegant jewelry details.
- App symbols remain recognizable; decorative styling must not obscure their identity.

## Project status
This repository is being bootstrapped. The Android project, complete app-filter mapping, artwork and installable APK are **not yet complete**.

## Planned deliverables
1. Native Android icon-pack APK compatible with Nova Launcher.
2. `appfilter.xml` covering the device's verified launcher activities.
3. Custom drawable assets with consistent Ruby styling.
4. Separate wallpaper and KWGT widget setup instructions.

## Constraints
- Free tools and workflows; personal use.
- No accounts, paid APIs, subscriptions or backend.
- Do not claim compatibility until installation and launcher testing are completed.

Build instructions will be added with the Gradle project scaffold.
