# Lotes de iconos — Etapa 5

`icons.json` es la fuente única de verdad para paquetes, activities, drawables y glifos. Los generadores y validadores no deben depender de un número fijo de entradas.

La hoja de contacto se genera desde los diez PNG de Etapa 1, cinco PNG del dock y todos los PNG del catálogo. Cada activity se clasifica como `verified` o `estimated`; no se infiere verificación a partir de que Nova la acepte.
